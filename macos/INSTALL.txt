Kaki Tools 1.5.0 — 原生 macOS 安装说明

安装
1. 从菜单栏 K 选择“退出 Kaki Tools”。
2. 将安装包里的 Kaki Tools 拖到 Applications，选择替换。
3. 从“应用程序”打开 Kaki Tools。

这是使用固定本地证书签名的新版本。适合此构建机本地使用，尚未使用 Apple Developer ID 或完成 Apple 公证。签名私钥只保存在构建机的登录钥匙串中，不在安装包内。

首次安装或旧授权失效时
• 调整窗口和自动粘贴：系统设置 → 隐私与安全性 → 辅助功能，允许 Kaki Tools。
• 区域截图：设置 → 权限与关于可检查当前程序的屏幕权限、申请授权或尝试截图。未确认不代表系统开关关闭。
• 授权后若系统要求退出并重新打开，请照做。
• 若只有截图异常，先完全退出，再从“应用程序”打开。仍无效或无法移除旧录屏条目时，双击本安装包中的“修复截图权限.command”。它要求所有 Kaki Tools 实例退出，只重置本软件录屏权限；辅助功能及历史不变。再允许屏幕录制，按系统提示退出重开。
• “重新授权.command”同时修复辅助功能和录屏，仅用于两类旧授权都失效；单独截图问题请用上述工具。
• 仍有问题：设置 → 权限与关于 → 复制截图诊断，包含版本、实际运行位置、签名和最近失败原因，不含账号和素材内容。
• 升级是否保留系统权限取决于实际签名身份；签名变更时可能需要重新授权。两种修复工具都只用于旧授权失效，不需要每次更新运行。

常用操作
⌘⇧V：打开剪贴板。
⌘⇧B：打开素材库。
⌘⇧2：拖选截图区域。
⌃⌥↩：让当前窗口铺满可用区域。

剪贴板历史和快捷键设置继续使用原来的本地数据目录。无需删除历史或卸载其他程序。

Studio 账号与素材
• 剪贴板顶部“素材库”打开原生 Studio 素材窗口；菜单栏设置 → 账号与连接，点击 KAKI Studio 卡片也可登录。
• 使用 Studio 的同一邮箱与密码，支持动态验证码或备用码。测试与正式环境分别登录。
• 新版首次连接测试站 test.kakiai.xin；如需正式账号，在账号页明确选择“正式环境”。
• 按现有 Studio 权限切换个人或团队工作区。支持搜索、分页、复制图片和下载图片/视频/音频。
• “复制代码”支持至多20项素材引用，需要 Studio 接收端适配；“复制素材”复制单项原素材，图片会转换成 PNG；“下载素材”保留原文件。
• 设置 → 下载可选择默认下载文件夹或每次询问，也可自选缓存磁盘、容量及未使用清理周期。
• 素材按需读取，窗口保持前台时自动检查新内容，失焦或关闭停止。当前不支持上传、修改或删除 Studio 素材。
• 剪贴板历史不会自动上传。退出账号清空在线列表和缩略图，已主动复制、下载的文件留在本机。

素材库可切换“最近生成”，显示当前账号最近50次任务中已完成的图片/视频，包括未入库结果。窗口在前台时每10秒检查一次，失焦/关闭停止。完整素材按需读取，不全量下载 COS；最近生成可按模型/日期/任务编号搜索。视频支持原生预览；未适配素材引用的 Studio 页面可使用复制图片或下载后拖入。

即梦连接
1.5.0在 设置 → 账号与连接 → 即梦 AI 提供经典 CLI 安装、检测、登录和连接。已有 CLI 不覆盖；未安装时从官方来源下载匹配本机架构的独立 CLI，不包含在应用安装包内。先正常登录 Studio 并选择环境、工作区，再完成本机即梦登录及关联确认。
支持文生视频、单图、首尾帧、多帧故事和全能参考，能力与清晰度按本机 CLI 版本检测。画布选择“即梦 CLI · 本机”，保存参考素材及连线；每次在 Tools 确认使用本人即梦额度。准备失败不提交；结果待核对时恢复原任务，不重复生成。完成结果通过原任务回传 Studio。
原 dreamina-canvas 官方网页/二维码授权连接保持独立。真实登录、关联和五方式付费出片需实机验收，不因安装完成而视为已验证。

修改快捷键
设置 → 快捷键：点击按键框，按住 Command / Option / Control 等修饰键并按下主键，再点击保存设置。Esc取消本次录制；Delete或“停用”清除单项，保存后生效。红色提示表示格式或应用内重复，请调整后再保存。窗口布局通过半屏、四分屏、三分屏、铺满/居中分类切换。

图片预览
本版修复新截图出现图片占位、重启后才恢复的问题。截图和复制图片的预览自动加载，不需要先设置 Studio 缓存。已保存的原图及历史记录继续保留。

快捷键显示
修正快捷键文字在按键框内偏上的问题；常用操作和各类窗口布局统一垂直对齐，设置与录制方式沿用原操作。
