## 客户端调用契约

| 功能 | 接口与约束 |
| --- | --- |
| 登录 | `POST /api/auth/login`，邮箱/密码，可选 code；响应 user 或 twoFactorRequired；只接收同源、Secure、有期限的 kaki_session Cookie |
| 恢复登录 | `GET /api/me`，向所选 Studio 发送 Cookie，401立即清理本地账号与过期会话 |
| 退出 | 先清理本地账号、本地会话、列表与缓存；`POST /api/auth/logout` 清理当前客户端服务器会话 Cookie，不干扰浏览器或 Studio 其他客户端 |
| 工作区 | `GET /api/workspaces`，恢复账号上次仍可用的工作区，否则选取个人区或首个可用区，过滤停用工作区；请求发送 X-Workspace-Id，权限由服务器判定 |
| 素材 | `GET /api/assets?pageSize=40&q=...&cursor=...`，解析 items/total/nextCursor，不走旧全量数组接口 |
| 最近生成 | `GET /api/jobs`，当前账号最近50次任务，筛选已完成且有 outputUrl 的 image/video；没有工作区过滤、服务端搜索或分页，不发送这些参数；模型/创建日期/短任务编号作为标题。包括未入库结果，也可能包含已入库结果，不自动写入素材库 |
| 私有文件 | 同源 `/api/private-files/:id` 或 `/api/files/...` 的 GET/HEAD，携带当前 Cookie；外部 HTTPS 媒体不携带 Cookie/Authorization/工作区头 |

这是同一用户身份、独立客户端会话；不读取浏览器 Cookie，不创建第二份用户库，不在测试/正式数据库之间复制账号。测试与正式环境会话文件分开存储。默认测试环境，用户可在账号页明确切换正式环境。

## 同步与性能

素材库为按需在线读取，不完整镜像到本地。素材窗口处于前台且为 key window 时，每次检查结束10秒后继续检查元数据，重新聚焦立即检查；失焦/关闭停止自动检查。生成中任务变为 done 后在下一次检查出现。手动刷新随时可用。素材库每页40条，最多保留400条列表元数据，较早素材可通过服务端搜索定位；类型过滤仅筛选已加载条目，保留原分页游标。后台更新保留选择与已加载较早页面；第一页和总量未变化时只读取一页。快照有变化时补齐先前可见范围再一起替换；失败保留原列表并显示重试提示。最近生成显示接口固定的最近50次任务中的图片/视频，搜索只在此窗口内进行，不支持提示词检索；素材库继续服务端搜索名称/标签/备注。缩略图最大280像素，缓存上限24条/12MiB。已入库素材优先缩略图；近期生成接口没有缩略图，图片按需读取最多8MiB用于280像素预览，视频使用占位图，避免为预览下载视频。完整图片复制最多32MiB，视频和音频通过临时文件下载，不整段载入内存。

所有请求拒绝重定向，避免会话跨域或 HTTPS 降级。读取边界：JSON2MiB，缩略图8MiB，图片复制32MiB，下载512MiB；下载进度和最终文件大小均有检查。密码仅在表单提交与请求期间存在内存，不保存到设置、日志或仓库；本地私有目录保存有期限的会话，文件权限0600、目录0700；不读取或迁移旧钥匙串项。

复制图片先验证尺寸，再后台转换为 PNG，以真实格式写入剪贴板。下载先以 HEAD 获取 MIME 建议文件扩展名，通过 macOS 保存面板选择路径，再保存原始字节。退出/换环境/换工作区会使旧请求结果失效，避免串账号或旧素材写入剪贴板。

当前没有自动上传剪贴板、上传收藏、修改或删除 Studio 素材、触发生成或修改积分。用户主动复制/下载的本地内容在退出账号后保留。

画布在POST前持久化token和参数，响应丢失先按原token找回；复制和派生清除提交身份，布局撤销保留原token/阶段。服务端专用路由冻结owner/workspace/project/node/设备代次与参数，用DB主键和CAS防重。`cli-<sha256>`为服务端保留命名空间；签名失效仍隔离平台队列/清扫/恢复/取消/结算，普通generate拒绝localCli字段。无需DB迁移，不进入平台积分账务。

本地0600 journal先持久化dispatch-intent，获服务端匹配任务/参数/阶段结构回执后才执行一次对应模式的生成命令。真实submit_id立即落盘；超时、无ID或提交回执丢失只能待核对，禁止自动重投。已有ID只query_result；下载视频必须通过真实文件大小/AVFoundation校验。上传只走原任务绑定的受权流式接口，保留额度、私有存储与原项目写权限。服务端同样解码校验；需COS私有存储启用，不回退公开URL。上传失败只重传已完成的视频；只有匹配jobId/submitId、done和受保护URL的结构回执才能将journal置completed。

慢查询与下载期间有独立心跳。真实阶段为本机提交/即梦生成/结果上传/待核对，不显示伪百分比。UNKNOWN无ID及已删除/无权节点不占用其他节点领单；它们仍不能重投或绕过回填权限。完整登录互传和真实付费生成尚待用户现场授权验收；模拟CLI与隔离构建通过不代表已安装应用或线上版本具有该功能。

文件剪贴板使用标准`public.file-url`并检查写入返回值；原生测试用私有pasteboard读取NSURL并校验视频/音频实际文件字节。已移除macOS拒绝的冗余legacy文件列表写入；不将原生标准表示通过当作真实浏览器跨应用粘贴已验收。浏览器只收到file://文本时明确提示拖入文件或使用「复制代码」。

## Seedance 模型与渠道适配

Tools 的常规 CLI 适配器保留 `resolution-five` 协议，并在设备注册的 `models` 中按本机 CLI 实际 help 能力上报模型。新增模型须在 text2video、image2video、frames2video、multimodal2video 四个命令中均明确列出；旧 CLI 继续只上报原模型。列表表示 CLI 能力，不表示用户会员资格或服务端可用权限。

| 模型 ID（任务 snapshot.model 必须原样保存） | 建议显示名称 | 分辨率 | 时长 |
| --- | --- | --- | --- |
| seedance2.0 | Seedance 2.0 · 普通 | 720p | 4–15秒 |
| seedance2.0fast | Seedance 2.0 Fast · 普通 | 720p | 4–15秒 |
| seedance2.0_vip | Seedance 2.0 · VIP | 720p / 1080p / 4k | 4–15秒 |
| seedance2.0fast_vip | Seedance 2.0 Fast · VIP | 720p | 4–15秒 |
| seedance2.0mini | Seedance 2.0 Mini | 720p | 4–15秒 |
| seedance2.5 | Seedance 2.5 · VIP · 常规生成 | 480p / 720p / 1080p | 4–30秒 |

`dreamina-multiframe` 的既有多帧协议不变。单图和首尾帧仍使用 `aspect: source`，不向 CLI 传 ratio。2.5 全能参考允许纯音频；图片≤30、视频≤10、音频≤10，总计≤50；视频和音频各自单条及累计时长2–30秒。2.0系列原限制不变。素材所有权、字节哈希、实际媒体解码校验及原任务防重机制保持。

Studio 后续需将这些 ID 纳入服务端模型白名单、任务 snapshot 校验、设备能力筛选及模型菜单，并按模型约束展示清晰度与时长。不可将 VIP ID 自动替换为普通 ID，也不可因会员权限错误自动重投到另一渠道。已有设备恢复接口不重新上报 models；Studio 完成适配后，需明确更新既有设备能力的接口或受控重新关联流程，不能假设旧设备记录会自动扩展。

样片模式尚未接入：本机 CLI 未公开 draft 参数或样片转正片命令，普通2.5的480p不能标成样片。未知样片模型 ID 被拒绝，不上报样片能力；后续必须以官方 CLI 的实际样片/正片协议单独适配。
